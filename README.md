# 交子行记 · 探索 Demo

以交子金融博物馆与北宋益州交子文化为背景的二维探索解谜网页游戏。玩家操控沈照跑图，与阿棠、灰衣客交谈，调查纸张、印版及工具等线索。

## 本地运行

需要 Node.js 20.19 或更高版本。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。使用 WASD、方向键或点击地面移动，靠近目标后按 E 交互；右上角菜单可查看对话回放与背包线索。

## 检查与构建

```sh
npm run typecheck
npm run build
npm run preview
```

## 项目文件

- `src/`：游戏剧情、探索交互和界面代码。
- `outputs/`：人物、场景、物品及 UI 图片素材。
- `docs/`：历史背景与内容校核文档。

当前为开发中的 Demo。剧情包含虚构人物与案件，历史内容以项目文档中的来源和校核说明为准。
