# 《交子行记：死人账》Demo UI 设计规范

## 设计目标

UI 使用墨青、纸白、暗朱红与旧金色，与人物和场景的二维古风线稿、低饱和平涂及旧纸颗粒保持一致。探索时只显示必要信息；调查和对白发生时，再展开完整操作层。

## 颜色

- 墨青：`#1F2623`，主界面底色与半透明面板。
- 纸白：`#E8DDC4`，证物、对白框和主要文字。
- 深青：`#395A57`，主要操作按钮。
- 暗朱红：`#98483B` / `#62332D`，人物名牌、任务标记和关键线索。
- 旧金：`#C7A66D`，章节信息、线索编号和细节提示。

## 探索界面

- 左上：章节名与当前目标。
- 右上：声音和暂停按钮。
- 右侧：竖向线索簿入口和收集进度。
- 左下：移动教学，数秒后自动淡出。
- 底部中央：交互提示，支持点击或键盘 `E`。
- 右下：场景名，只承担气氛与位置提示。

## 调查界面

- 左侧：证物纸张观察区域，保留放大镜、灯光和纸面状态变化。
- 右侧：证物编号、观察结论和操作按钮。
- “移到灯下”后，异常断线由灰褐色变为暗朱红，线索簿进度更新为 `1 / 4`。
- 证物本身不生成可读历史文字，避免错误史料进入画面。

## 对话界面

- 人物立绘位于左下，使用设定板的正面形象作为临时原型素材。
- 对话框使用纸张色块与暗朱红名牌。
- 两项回应横向排列；窄屏时改为上下排列。
- 回应后保留一句人物反馈，再进入下一个场景。

## 线索簿

- 从屏幕右侧滑入。
- Demo 设四条线索：熟悉的刻痕、残破告示、第二张凭据、旧工具匣。
- 已获得线索使用暗朱红编号和浅红底色，其余内容降低透明度。
- 支持按钮或键盘 `J` 打开和收起。

## Demo 操作流程

1. 点击“查看破损纸张”或按 `E`。
2. 在调查界面点击“移到灯下”。
3. 点击“记录线索并继续”。
4. 选择沈照对阿棠的回应。
5. 进入交子铺外景，再次点击底部交互提示。
6. 回应灰衣客后进入交子铺空室结尾。

## 响应式规则

- 桌面端：调查层左右分栏，对话选项横排。
- 移动端：调查层上下排列，对话选项纵排，角色立绘降低透明度，场景名和移动键教学自动隐藏。
- 所有按钮保留键盘焦点样式；支持 `E`、`J` 和 `ESC`。
