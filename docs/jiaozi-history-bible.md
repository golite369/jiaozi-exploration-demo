# 《交子行记》历史与展陈使用规范

## 时间与地点

- 主线发生在北宋天圣年间的益州成都。
- 官交子诞生以公元 1024 年为博物馆叙事时间节点；制度背景是天圣元年设置益州交子务，此后由政府发行官交子。
- 场景应体现四川铁钱流通、成都商业繁盛、造纸与雕版印刷成熟的城市环境。

## Demo 必须讲清的三层关系

1. **铁钱之重**：四川以铁钱为主要流通货币，价值较低且携带不便，商贸需要更轻便的凭证。
2. **铺户之信**：民间交子铺户先收现钱，再开纸券。铺户信用、联保和兑付能力决定私交子能否被接受。
3. **交子务之制**：民间铺户出现不能兑现、争讼等问题后，益州交子务接管发行，官交子依靠发行管理和本钱兑付维持信用。

## 与交子金融博物馆展陈的对应

- **裂纸为币·繁华蜀都**：铁钱沉重、成都商贸和交子产生的城市背景。
- **裂纸为币·制楮为券**：楮纸、印刷、铺户收钱开券，以及纸面如何承载信用。
- **铜钱兑飞钱**：用于解释飞钱是纸质汇兑凭证，不能与四川交子直接混称。
- **成都十二月市**：可用于街巷、市集告示和成都商业生活的环境叙事。
- **交行天下**：官交子的发行管理、兑付和后续纸币发展。

## 可直接使用的史实细节

- 私交子由民间铺户经营，后来形成十六户富商联保。
- 私交子印文可见屋木人物，铺户以押字、隐密题号和朱墨相错作私记。
- 益州交子务负责官交子的发行管理，并以铁钱本钱支持兑付。
- 益州交子务另置抄纸院，从造纸环节加强纸张管控，以减少仿造官交子的风险。
- 飞钱、交引、交子都是纸质信用工具，但功能与制度不同，台词中不能混称。

## Demo 中的虚构内容

以下内容只服务于谜题，不能写成宋代通行制度或真实馆藏说明：

- 沈照、阿棠、灰衣客及其身份关系。
- 西坊旧交子铺、乙柜、北巷纸栈、河边旧抄纸作坊。
- 铺户私记被削去一角、两张券样断线重合、回刀痕、失踪木版。
- 写有“益州交子务”“见钱”的包版告示及本案追查路线。
- “交子务外廊”的具体空间布局、退验盘、发券簿空栏、递纸竹签，以及有人冒用沈照姓名送验湿纸。

游戏内说明应使用“剧情物证”“史实对应”等措辞，把上述机关与史实分开。

## 后续美术与文本禁区

- 不直接照搬现存南宋会子版、明代宝钞或清代银票的版式充当北宋交子。
- 不把飞钱写成交子，也不把铺户私记写成益州交子务官印。
- 不虚构“削角即官方作废”“单块木版即可印出完整官交子”等制度。
- 不使用银票、银元、票号、钱庄等容易指向明清金融业的核心术语。
- 博物馆知识优先放入可调查物、线索簿和人物争辩中，避免连续讲解式台词。
